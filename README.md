# Agentic Software

Minimal, static presentation website for Agentic Software Ltd.

AI strategy, diligence and implementation for private equity, venture capital
and portfolio companies.

## Preview

No installation or build step is required.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173.

## Hosting

GitHub Pages: deploy from `main`, `/ (root)`. Custom domain:
`agentic-software.co.uk`. The `CNAME` file retains the domain setting and
`.nojekyll` serves the static files directly.

## Content

The architecture image is an AI-generated editorial visual, not a company office.
The site loads no external fonts, scripts or analytics.
